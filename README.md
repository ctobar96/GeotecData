# GeotData Pipeline — Análisis Geotécnico y Geoespacial

GeotData Pipeline es un proyecto orientado a integrar conocimientos de Ingeniería Civil Geológica, Data Engineering, Data Science y Machine Learning para el procesamiento, análisis y visualización de información geológica y geotécnica.

El proyecto busca desarrollar un flujo reproducible de procesamiento de datos que permita gestionar información proveniente de ensayos de mecánica de suelos, investigaciones geotécnicas y fuentes cartográficas.

**Principales objetivos:**

- Procesar y validar datos de ensayos geotécnicos SPT, CPT y velocidad de onda de corte (Vs).
- Automatizar cálculos y análisis relacionados con la mecánica de suelos y evaluación de licuación.
- Integrar información geológica y topográfica mediante herramientas GIS.
- Desarrollar visualizaciones interactivas de perfiles estratigráficos y parámetros geotécnicos.
- Aplicar técnicas de análisis de datos y Machine Learning para explorar patrones y apoyar la evaluación geotécnica.
- Construir una arquitectura reproducible utilizando herramientas de Data Engineering.

**Tecnologías previstas:** Python, Pandas, GeoPandas, DuckDB, Parquet, Streamlit, Plotly, Rasterio, Docker y Machine Learning.
